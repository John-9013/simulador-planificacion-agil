# Simulador Interactivo de Planificación Ágil

Este repositorio contiene la implementación del proyecto simulador de planificación ágil para la asignatura de **Procedimientos Técnicos en un Modelo Ágil** de la **Universidad TecMD**.

## 📌 Autor
* **Estudiante:** John Edison Sarmiento Jaimes
* **Institución:** Universidad TecMD

## 🚀 Descripción del Proyecto
El sistema simula un entorno de planificación y seguimiento de proyectos bajo metodologías ágiles (Scrum/XP), gestionando:
* Historias de usuario y estimación de puntos de historia.
* Asignación de desarrolladores y simulación de velocidad de equipo por Sprints.
* Gráficos de trabajo restante (Burndown Chart) e interfaz gráfica interactiva.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python 3.x
* **Interfaz Gráfica:** Tkinter
* **Control de Versiones:** Git & GitHub
